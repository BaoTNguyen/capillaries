Analyze and propose improvements to the **{{process_name}}** process at **{{company_name}}** in the **{{department}}** department.

Current state:
- Process description: {{process_description}}
- Number of steps: {{num_steps}}
- Average completion time: {{avg_completion_time}}
- Frequency: {{process_frequency}} (e.g., daily, weekly, per transaction)
- People involved: {{roles_involved}}
- Tools currently used: {{current_tools}}
- Known bottlenecks: {{known_bottlenecks}}
- Error/rework rate: {{error_rate}}%

Perform the following analysis:
1. **Current State Map** — Document each step: action, owner, average time, inputs, outputs, and handoff points. Identify wait times between steps.
2. **Waste Identification** — Using lean principles, flag: unnecessary steps, redundant approvals, manual work that could be automated, information that is entered multiple times, and waiting/idle time.
3. **Root Cause Analysis** — For each bottleneck, identify why it exists using the 5 Whys technique.
4. **Future State Design** — Propose an optimized process with: steps eliminated, steps automated, steps combined, and new tools introduced. Show the revised step count and estimated time savings.
5. **Automation Opportunities** — Specific tasks that can be automated, recommended tools, and estimated implementation effort.
6. **Implementation Plan** — Phased rollout: quick wins (week 1-2), medium changes (month 1-2), larger transformations (quarter 1-2).
7. **Expected Impact** — Quantify: time savings per occurrence, annual hours saved, error rate reduction, and estimated cost savings.

Output as a process improvement proposal with before/after comparison tables.
